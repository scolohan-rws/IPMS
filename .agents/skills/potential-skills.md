# Potential skills

- `weekly-repository-audit`: Run a read-only full-repository audit on a schedule,
  combine deterministic checks with AI findings, and emit JSON plus Markdown.
- `lambda-scaffolder`: Create a `camelCaseLambda.ts` handler, typed event factory,
  tests, Lambda definition, route registration, and README entry.
- `external-integration-builder`: Add a typed external-system client with DTO
  mapping, timeouts, retries, idempotency, safe errors, and tests.
- `sst-infrastructure-review`: Review SST/Pulumi resource identity, permissions,
  authorizers, SSM dependencies, stage safety, and replacement risk.
- `api-contract-review`: Compare routes, request/response types, README, and a
  future OpenAPI contract for breaking changes.
- `test-gap-analysis`: Map handlers and services to success, validation, auth,
  dependency failure, timeout, and regression-test coverage.
- `observability-audit`: Check Lambda structured logging, correlation IDs,
  metrics, alarms, sensitive-data exposure, and CloudWatch usefulness.
- `dependency-upgrade-review`: Review one dependency upgrade at a time, consult
  release notes, identify breaking changes, and verify lockfile scope.
- `incident-triage`: Correlate API Gateway and Lambda symptoms, logs, metrics, and
  recent releases into a root-cause hypothesis and rollback decision.
